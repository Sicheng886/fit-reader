# TrainingPeaks 负荷模型（CTL / ATL / TSB）

## 定义

- **CTL（慢性训练负荷，"体能"）**：每日 TSS 的 42 天指数加权平均，代表长期训练积累出的体能水平。变化缓慢，是训练成果的度量。
- **ATL（急性训练负荷，"疲劳"）**：每日 TSS 的 7 天指数加权平均，代表近期训练造成的疲劳。变化迅速。
- **TSB（训练压力平衡，"状态"）= CTL − ATL**：正值表示新鲜（体能 > 疲劳），负值表示带疲劳训练。无训练日按 TSS=0 参与衰减——停训时 CTL 缓慢下滑、ATL 快速回落。

## TSB 解读标尺

| TSB 区间 | 状态含义 |
|---|---|
| > +25 | 过度新鲜，可能停训过久、体能流失中 |
| +5 ~ +15 | 比赛/测试的理想新鲜区间（taper 目标） |
| -10 ~ +5 | 中性，适合正常训练或低强度比赛 |
| -10 ~ -30 | 生产性训练区间：带可控疲劳积累负荷，体能增长的主区间 |
| < -30 | 深度疲劳：受伤与过度训练风险显著升高，应安排减量恢复 |

## CTL 安全增幅

CTL 周增幅不宜超过 5–7 点（约 5–10% 相对增幅）；长期超速堆量是过度训练与伤病的主要诱因。评估用户负荷增长时，先看绝对增幅，再结合其 CTL 基数判断可持续性。

## 减量（Taper）原则

- 目标：比赛日 TSB 落在 +5 ~ +15（新鲜但不明显掉体能）。
- 减量期通常 7–14 天，训练量（时长/频次）削减 40–60%，**强度保留**——维持少量 Z4–Z5 短间歇防止体能流失与"腿沉"，避免完全停训。
- 赛前 48 小时：以短时长低强度 + 几组 opener（短暂高强度唤醒）为主。
- CTL 本身在减量期会小幅下滑（每天约 0.5–1 点），这是用少量体能换大量状态的正常交换，不必恐慌。

## 强度分布类型

按低（Z1–Z2）/中（Z3–Z4）/高（Z5–Z7）三区时长占比划分：

- **polarized（极化）**：低 ≥75% 且高 > 中。大量轻松 + 少量很硬，耐力项目的主流证据支持结构。
- **pyramidal（金字塔）**：低 > 中 > 高。最常见的自然分布，适合多数业余骑手。
- **sweet_spot（甜区取向）**：中强度占比偏高。时间效率好但恢复代价大，长期单一甜区结构易陷入"中等强度陷阱"（不够轻松也不够硬），需警惕疲劳累积。

评估时结合训练阶段：筑基期宜极化/金字塔；赛前专项期可短期提高中高强度占比。
